# 📊 Sales Dashboard - Power BI

## Project Description

This dashboard was developed in Power BI for sales analysis and data visualization practice.

Features included:

- Total Sales indicator
- Total Profit indicator
- Total Units Sold
- Sales by Country chart
- Country filter
- Product distribution chart

## Objective

The purpose of this project was to improve skills in:

- Power BI
- Data visualization
- Dashboard design
- Interactive reports
- Data analysis
