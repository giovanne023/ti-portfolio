# 🖧 Rede Corporativa Cisco - Packet Tracer

## 📌 Descrição do projeto

Projeto de rede corporativa desenvolvido no Cisco Packet Tracer simulando um ambiente empresarial com:

- Roteador principal
- Switch central
- Switches secundários
- Servidor DHCP
- Múltiplos computadores clientes
- Distribuição automática de IP

---

## ⚙️ Funcionalidades implementadas

✅ Configuração de rede corporativa

✅ Servidor DHCP ativo

✅ Distribuição automática de IP

✅ Comunicação entre dispositivos

✅ Teste de conectividade utilizando Ping

✅ Estrutura hierárquica de rede

---

## 🛠️ Tecnologias utilizadas

- Cisco Packet Tracer
- Redes TCP/IP
- DHCP
- Switches Cisco 2960
- Router Cisco 2811

---

## 🎯 Objetivo

Praticar conceitos de:

- Redes corporativas
- Endereçamento IP
- DHCP
- Configuração de dispositivos Cisco
- Estruturação de topologia de rede
