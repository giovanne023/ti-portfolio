# 🖥️ IT Support Ticket Dashboard

## Project Description

Dashboard developed in Power BI focused on IT Support and Help Desk metrics.

Features included:

- Total Tickets
- Open Tickets
- Closed Tickets
- Average Resolution Time
- Tickets by Category
- Tickets by Priority
- Tickets by Technician
- Department Filter

## Objective

The goal of this project was to practice:

- IT Support metrics
- Help Desk concepts
- Service Desk analysis
- Dashboard creation
- Data visualization

## Technologies Used

- Power BI
